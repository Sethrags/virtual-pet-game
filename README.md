# Pygame Virtual Pet

A python-based virtual pet game built using Pygame. The program simulates the care of a pet. The program gives the user the option of feeding the pet, sleeping the pet, and paying minigames on the side for a reward (Food).

## Key Features

### Core Mechanics
    Pet simulation: Fully animated pet 
    Life Systems: Systems such as Hunger, hapiness and energy
    Pet state Storage: Save/load functionality
### Advanced Integration
    Real-Time Weather: Using a Weather API call
    Day/Night: Using the Sleep function
    Minigames: Using the Game function 
    Game over system: (For future integration in later development)

# System Requirements/ Dependencies
All system dependencies can be downloaded using except for Python, which has to be
Previously downloaded prior to using any ***"pip"*** commands. The python dependencies can be used using the command below:
```
pip freeze > requirements.txt
```
Otherwise these are all the dependencies listed that are used for this specific project program:
```
**Python** python 3.13.7 (Recommended)
**Pygame** Pygame 2.6.1 (Recommended)
**requests** Requests 2.32.5 (Recommended)
```
# Installation and Setup

### Downloading repository
```
git clone https://github.com/HowellBrent/3300-Software-Tamagotchi-
cd 3300-Sotfware-Tamagotchi
```
### Environment Configuration (recommended)
### *Setting An Environment is always recommended when dealing with programs with dependencies, in this way one does not have to worry about having any issues when running the program.*

MacOS / Linux:
```
python -m venv venv
source venv/bin/activate
```
Windows:
```
python -m venv venv
.\venv\Scripts\activate
```
### Installing Dependencies (Inside Environment)
```
pip install -r requirements.txt
```

# Running the application
1. Open a terminal or command prompt
2. Travel to the downloaded repository directory in your file system
3. (Must have installed python) in the terminal input:
```
python main.py
```
4. The application should run at this point
